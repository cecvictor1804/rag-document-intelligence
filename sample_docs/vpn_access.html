Remote VPN Access

To work remotely, connect to the corporate VPN. Install the VPN client from the IT software catalog, then sign in with your Google Workspace credentials and approve the two-factor prompt.

Supported platforms

The VPN client is supported on Windows, macOS, and Linux. Mobile access is available through the same client on iOS and Android.

Troubleshooting

If the VPN fails to connect, first confirm your internet connection, then restart the client. Persistent failures should be reported to the network team with the error code shown in the client.
